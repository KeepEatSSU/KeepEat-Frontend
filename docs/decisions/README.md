# 결정 기록

이 디렉터리는 KeepEat 프론트엔드의 구조적 결정과 되돌리기 어려운 정책 변경을 남기는 곳이다.

현재 기록된 결정 문서는 없다.

## 언제 작성하나

- 라우팅 구조를 바꿀 때
- API 클라이언트/상태 관리 전략을 바꿀 때
- 디자인 시스템의 큰 원칙을 바꿀 때
- 캐시/동기화/오프라인 정책을 정할 때
- 테스트 전략이나 QA 기준을 바꿀 때

## 파일 이름

권장 형식:

```text
YYYY-MM-DD-short-title.md
```

예시:

```text
2026-06-23-use-context-for-auth-state.md
```

## 템플릿

```md
# 결정: 제목

## 상태

제안됨 / 채택됨 / 폐기됨 / 대체됨

## 배경

왜 이 결정을 해야 하는지.

## 결정

무엇을 선택했는지.

## 대안

검토한 다른 선택지.

## 영향

코드, UX, 운영, 테스트에 미치는 영향.

## 확인 필요

아직 검증되지 않은 점.
```
